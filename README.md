# Sauurabh Srivvastava – Portfolio (React + Vite + GSAP + Lenis)

Run locally:  npm install && npm run dev
Build:        npm run build

Deploy on Vercel: push to GitHub -> Vercel -> Import Project -> Deploy (Vite is auto-detected).
Or drag this folder into https://vercel.com/new.

Content: src/data.js   Animations + smooth scroll: src/motion.js   Photos: public/img
Fonts are bundled (no external requests).
