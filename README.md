# Sauurabh Srivvastava – Portfolio (React + Vite)

Run locally:  npm install && npm run dev
Build:        npm run build

Deploy on Vercel: push to GitHub → Vercel → Import Project → Deploy (Vite is auto-detected),
or drag the folder into https://vercel.com/new.

Edit content in src/data.js. Photos are in public/img.
